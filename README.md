## Run locally
Open `index.html` directly in your browser, or serve the folder with any static server.

## Publish on GitHub Pages (stable shareable link)
This repo includes a ready workflow at `.github/workflows/pages.yml`.

1. Create a new empty GitHub repository.
2. Push this folder to the `main` branch.
3. In GitHub, open **Settings → Pages** and set **Source = GitHub Actions**.
4. Wait for the **Deploy static site to GitHub Pages** workflow to finish.
5. Share the generated URL:
	 - `https://<your-github-username>.github.io/<repo-name>/`

Notes:
- If you want to share the luxury final page directly, send:
	- `https://<your-github-username>.github.io/<repo-name>/luxury-home.html`
- Same link stays valid; after every push to `main`, the site auto-updates on refresh.
